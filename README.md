# 栖水园 · 一院江南

一座可旋转、缩放、漫游与共同生活的 3D 江南微缩庭院。以苏式园林为意象，粉墙黛瓦、曲桥碧池、竹影茶亭、四时晨昏，都在浏览器中实时生成。

## 立即游园

### 单文件版（最简单）

直接双击 **`栖水园.html`**。界面、样式和全部庭院模块均已内嵌，无需安装或启动服务；首次打开需要联网加载 Three.js 3D 引擎。

### Windows 本地服务（源码版）

双击 **`启动栖水园.bat`**，脚本会启动本地预览服务并打开浏览器。

### 命令行

在项目目录运行：

```bash
node server.mjs
```

然后访问 **http://127.0.0.1:8080**。端口被占用时可运行 `node server.mjs 8081`。

也可使用 VS Code 的 Live Server 等任意静态服务器。由于浏览器对本地 ES Module 的安全限制，源码版请不要直接以 `file://` 双击 `index.html`；已经封装好的 **`栖水园.html`** 不受此限制。

> 首次打开需要联网，从 jsDelivr 加载 Three.js；字体可从 Google Fonts 加载，失败时自动使用本机宋体。场景、模型、纹理、音乐和音效全部程序化生成，不需要下载模型或音频素材。

## 园中雅趣

- **任意角度赏园**：左键拖动环视，滚轮缩放，右键拖动平移；手机支持单指旋转、双指缩放与平移。
- **撒饵观鱼**：18 尾拥有独立名字、花色与体形的锦鲤，会漫游、避让、摆尾、浮沉、争抢并真正吃掉鱼食，伴随涟漪、气泡、水花与啄食声。既可点击池水，也可用「池心撒饵」或空格快捷投喂。
- **与园互动**：轻点锦鲤、门扉、灯笼、风铃、茶席、匾额、荷花、树木和湖石，发现各自的回应与诗意手记。
- **画中漫游**：六处精选镜头，自动移步换景，可随时进入下一景或拖动退出。
- **四时晨昏**：春柳、夏荷、秋枫、冬雪；时辰滑杆从清晨到月夜，暖灯、星空和萤火随夜色出现。
- **烟雨与晴雪**：斜织雨丝、池面雨滴涟漪、缓慢飘雪、晴空飞鸟和夜间萤火。
- **实时国风声音**：Web Audio 生成五声音阶拨弦、流水、风声、鸟鸣，及喂鱼、扑水、风铃、钟、雨、按钮、留影等音效。
- **庭院留影**：将当前实景装裱成带园名、季节与印章的 PNG 明信片。
- **造园设置**：时辰、音量、画质、自动环视、互动标签；本机自动保存偏好。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `1` | 进入 / 退出撒饵观鱼 |
| `Space` | 喂鱼模式下在池心撒饵 |
| `2` | 开启 / 结束画中漫游 |
| `3` | 切换天气 |
| `4` | 切换清晨 / 月夜 |
| `M` | 开关声音 |
| `P` | 保存庭院留影 |
| `H` | 游园指南 |
| `F` | 全屏 |
| `Esc` | 退出当前互动或关闭弹窗 |

## 项目结构

```text
栖水园.html                完整单文件版，可直接双击打开
index.html                 源码版页面与完整中文界面
style.css                  宣纸、黛绿、朱砂视觉系统与响应式布局
js/main.js                 渲染、地基、镜头、光影、交互及功能整合
js/architecture.js         主厅、茶亭、廊桥、月洞门与建筑细部
js/nature.js               竹松柳枫、湖石、荷莲、花草与季节变化
js/pond.js                 精细锦鲤、鱼食生态、水波、焦散、涟漪与粒子
js/weather.js              雨、雪、微尘、萤火与飞鸟
js/audio.js                无素材依赖的程序化音乐和音效
server.mjs                 零依赖本地静态服务
build-standalone.mjs       从最新源码重新生成单文件版
启动栖水园.bat             Windows 一键启动
preview-day.png            高画质日间实景
preview-night.png          高画质秋夜实景
preview-feeding.png        锦鲤争食实景
```

修改源码后，运行 `node build-standalone.mjs` 即可重新生成单文件版。

## 画面与性能

- Three.js WebGL 实时渲染，ACES 色调映射、柔和阴影、环境反射与轻微泛光。
- 提供「精致 / 平衡 / 轻盈」三档画质，会自动限制高分屏像素比。
- 瓦片、石岸、植物和鱼食使用复用几何或实例化；天气粒子合批绘制。
- 遵循系统“减少动态效果”设置；页面切到后台时暂停声音。
- 推荐最新版 Chrome / Edge / Firefox，并开启硬件加速；建议佩戴耳机。

## 技术说明

本项目为纯前端静态作品，不上传任何操作数据。偏好仅保存于浏览器 `localStorage`；留影只在本机生成。音频遵循浏览器自动播放策略，点击「推门入园」后才会启动。
